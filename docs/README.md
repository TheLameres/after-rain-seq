# Документация after-rain-seq

Вся проектная документация собрана здесь. В корне репозитория остаётся только
`README.md` как точка входа в проект.

## Содержание

| Файл | Что это |
|---|---|
| [AGENTS.md](AGENTS.md) | Планы и задачи: разбивка на фазы, артефакты для агентов, история решений. Основной рабочий документ. |
| [push2_dubtechno_plan_v5_4.md](push2_dubtechno_plan_v5_4.md) | Полный исходный план v6.0: архитектура, фазы, требования. |
| [track-hierarchy.md](track-hierarchy.md) | Иерархия `Track` → `MelodicTrack` / `DrumTrack`, профили как данные. |
| [display.md](display.md) | Подсистема экрана Push 2: USB bulk-интерфейс, рендеринг, отдельно от MIDI. |
| [mutation-manual-spec.md](mutation-manual-spec.md) | Спецификация ручной мутации: `pending`, граница цикла дорожки, линейная история версий, откат. |
| [project-status-2026-11-10.md](project-status-2026-11-10.md) | Отчёт о состоянии работ на 10 ноября 2026 г. Сохранён как исторический снимок; указанные в нём коммиты в этой копии репозитория отсутствуют. |

## Что где искать

- **Как устроен код** — `AGENTS.md`, затем `track-hierarchy.md`.
- **Почему мутация теперь ручная** — `mutation-manual-spec.md`.
- **Как работает экран** — `display.md`.
- **Что было сделано к дате** — `project-status-2026-11-10.md`.

Патчи по этапам реализации лежат в `../patches/`, вне этой папки.
