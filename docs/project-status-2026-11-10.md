class VersionHistory(Generic[T]):

    - versions: list[T]    # стек версий

### 3. **Ручная мутация + граница цикла** (коммит `387c54e`)

```python
MutationEngine:
  - request_mutation(track_name, cycle_beats)    # пользователь ставит в очередь
  - _apply_requested(current_beat)               # ждёт границы цикла
  - _cycle_index(beat, cycle_beats)              # detect cycle crossover
  - _commit_manual(track_name, beat)             # apply mutation + increment counter
```

**Как работает:**
1. Вызов `request_mutation()` добавляет дорожку в `_requests` очередь
2. На каждом тике `tick()` вызывает `_apply_requested()`
3. Функция проверяет: поросла ли `cycle_index` (т.е. пересекли ли границу цикла)?
4. Если да — применяет мутацию через `_commit_manual()`

**Статус:** ✅ **Функционирует**, но не связано с:
- флагом `pending` на track
- снимками (snapshots) для истории
- REPL/UI командами
