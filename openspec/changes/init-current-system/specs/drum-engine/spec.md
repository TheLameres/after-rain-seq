# Spec Delta

## Purpose

Drum-машина: евклидовы ритмы по 16 GM-лейнам на общей сетке шагов, три уровня
velocity, детерминированный резолвинг шага в ноту и мост в транспорт.

## ADDED Requirements

### Requirement: 16 lane на GM-нотах
Drum-дорожка SHALL состоять ровно из 16 лейнов на GM-нотах 36–51 и играть их
по отдельному каналу (номер 9), независимо от тональности сессии.

#### Scenario: Смена тональности не влияет на drum
- **WHEN** пользователь меняет Root или Scale
- **THEN** drum-паттерн звучит без изменений

### Requirement: Общая сетка шагов
Drum-дорожка SHALL использовать одну сетку шагов (16 по умолчанию, опции
16/32/48/64), общую для всех лейнов.

#### Scenario: Увеличение сетки
- **WHEN** пользователь задаёт 32 шага
- **THEN** все 16 лейнов играют по сетке из 32 шагов

### Requirement: Евклидова генерация
Каждый лейн SHALL задаваться евклидовым ритмом (число пульсов на сетке);
генерация SHALL быть кешированной — повторные построения одного набора
параметров не пересчитываются.

#### Scenario: Кеш евклидова паттерна
- **WHEN** два лейна имеют одинаковые параметры евклидова ритма
- **THEN** второй лейн использует кешированный результат без пересчёта

### Requirement: Три уровня velocity
Drum-машина SHALL поддерживать три уровня velocity — ghost, normal, accent —
и выбирать их при редактировании сетки (в том числе силой нажатия пада).

#### Scenario: Удар accent
- **WHEN** пользователь ставит шаг на лейн с уровнем accent
- **THEN** шаг запоминается с velocity верхнего диапазона (120–127)

### Requirement: Пауза и one-shot
Пауза в лейне SHALL кодироваться нулевой амплитудой; каждый шаг drum SHALL
воспроизводиться как one-shot с фиксированной длительностью.

#### Scenario: Снятие шага
- **WHEN** пользователь снимает шаг с лейна
- **THEN** в паттерне на этом шаге нулевая амплитуда (пауза)

### Requirement: Резолвинг шага в ноту
Резолвинг номера шага в GM-нотy лейна SHALL определяться единой функцией,
общей для всего проекта.

#### Scenario: Один резолвер
- **WHEN** разным подсистемам (UI-редактор и движок) нужен шаг → нота
- **THEN** обе подсистемы получают одинаковый результат из одного источника

### Requirement: Предпрослушка лейна
Система SHALL проигрывать одиночный удар лейна при его выборе, если
предпрослушка включена в конфигурации drum.

#### Scenario: Выбор лейна с предпрослушкой
- **WHEN** пользователь выбирает лейн (включена опция preview)
- **THEN** звучит один удар выбранного лейна с заданной velocity
