# Spec Delta

## Purpose

Управление и дисплей Ableton Push 2: рендеринг 960×160 BGR565 с dirty-регионами,
композитор экранов на frozen view-DTO, навигация по экранам, энкодеры, кнопки
мутации и сетка падов версий.

## ADDED Requirements

### Requirement: Целая отправка кадра по dirty
Дисплей SHALL получать кадр только целиком (960×160 BGR565); система SHALL
отправлять кадр по факту изменений и keepalive раз в ~1 с, так как после 2 с
тишины дисплей гаснет.

#### Scenario: Статичный экран
- **WHEN** экран не меняется
- **THEN** кадр не перерисовывается, кроме keepalive раз в секунду

### Requirement: Dirty-регионы
Система SHALL инвалидировать и перерисовывать только изменённые регионы
кадра: пересекающиеся и смежные прямоугольники объединяются, выход за
64 региона деградирует к полной перерисовке.

#### Scenario: Локальное изменение
- **WHEN** меняется одно значение в статус-баре
- **THEN** перерисовывается только регион статус-бара, остальной кадр не трогается

### Requirement: Экраны и навигация
Приложение SHALL предоставлять экраны TRACKS (список дорожек, 8 на страницу),
TRACK (детали дорожки), GLOBAL (root/scale/bpm/swing), SYNC (клок),
PORTS (порты), VERSIONS (сетка версий); верхняя колонка табов переключает
экраны, активная подсвечивается LED.

#### Scenario: Переход на экран дорожки
- **WHEN** пользователь выбирает дорожку на TRACKS и жмёт Right
- **THEN** открывается экран TRACK выбранной дорожки, LED табов обновляется

### Requirement: Track-энкодеры
Восемь энкодеров на экране дорожки SHALL редактировать параметры дорожки
(в том числе плотность — где она применима, источники, порт-назначение на
PORTS); плотность SHALL реально менять звучание слайсеров.

#### Scenario: Плотность меняет звук
- **WHEN** пользователь уменьшает плотность слайсера энкодером
- **THEN** число активных шагов паттерна уменьшается в звучании

### Requirement: Глобальные энкодеры
Энкодеры Tempo и Swing SHALL управлять глобальными параметрами; касание
энкодера SHALL отделяться от вращения (отдельные события).

#### Scenario: Изменение BPM
- **WHEN** пользователь вращает энкодер Tempo
- **THEN** BPM сессии меняется, статус-бар и экран GLOBAL обновляются

### Requirement: Кнопки мутации на Push 2
Кнопка NEW SHALL ставить шаг мутации на выбранную дорожку, Shift+NEW — на
все; кнопка UNDO SHALL откатывать выбранную дорожку на одну версию (на корне
— отказ).

#### Scenario: Shift+NEW
- **WHEN** пользователь жмёт Shift+NEW
- **THEN** pending-мутация ставится на все дорожки сессии

### Requirement: Экран VERSIONS
Кнопка Duplicate SHALL открывать экран VERSIONS: колонка = дорожка, строка =
версия, текущая подсвечена цветом дорожки, пад = переход на версию; при
более чем 8 дорожках или 8 версиях — пагинация по страницам.

#### Scenario: Сетка из двух дорожек
- **WHEN** в сессии 2 дорожки и у первой 3 версии
- **THEN** первая колонка показывает 3 пада версий, вторая — только текущую версию

### Requirement: Ошибки и flash-сообщения
Отклонённые действия (неудачное удаление, ошибки экранов) SHALL показываться
flash-сообщением в углу дисплея с ограниченным временем жизни.

#### Scenario: Ошибка экрана
- **WHEN** действие отклоняется с ошибкой
- **THEN** пользователь видит flash-сообщение с текстом ошибки, экран остаётся на месте

### Requirement: Потокобезопасная очередь UI
MIDI-вход Push 2 SHALL доставлять события в главный цикл через потокобезопасную
очередь ограниченной ёмкости с вытеснением старейших при переполнении.

#### Scenario: Переполнение UI-очереди
- **WHEN** очередь событий UI заполняется
- **THEN** старейшее событие вытесняется, приложение продолжает работать

### Requirement: Карта кнопок по спеке устройства
Карта кнопок и энкодеров SHALL соответствовать официальной спеке Push 2:
track-энкодеры 1–8 = CC 71–78, tempo = CC 14, swing = CC 15, master = CC 79,
Browse = CC 111, NEW = CC 87, Duplicate = CC 88, UNDO = CC 119.

#### Scenario: Трек-энкодер 8
- **WHEN** пользователь вращает восьмой track-энкодер
- **THEN** приложение получает CC 78
